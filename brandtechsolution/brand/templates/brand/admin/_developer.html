How the Teklora MCP Server Works

The MCP server runs locally via stdio and authenticates against Teklora using your API key. Here is what it gives your agent access to:

1. Developer Identity & Profile

teklora_get_developer_profile gives the agent your full profile: primary role, preferred programming languages, frameworks, GitHub username, and scopes.

2. Tasks & Ladder Progression

teklora_list_my_tasks, teklora_get_task_details, and teklora_complete_task_assignment. When your agent marks your assignment complete, the task automatically advances on the platform ladder to In Review.

3. Repositories & Task Creation

teklora_list_repositories and teklora_create_task allow your agent to view synched repositories and file follow-up engineering tasks.

4. Platform Knowledge Base

teklora_search_knowledge_base enables semantic search across architecture specifications (docs/specs/), implementation plans, and system documentation.
