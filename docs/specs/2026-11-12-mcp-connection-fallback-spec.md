# MCP bounded TCP address fallback

The zero-dependency developer MCP client must not exhaust the calling agent's tool timeout on unreachable IPv6 addresses when IPv4 works. Apply a connection factory only to this client's urllib HTTP/HTTPS handlers: each resolved TCP address gets at most 3 seconds, within a shared 10-second TCP budget. Preserve resolver order and try remaining addresses on connection errors. Close failed sockets; restore the existing 30-second socket I/O timeout after connection. DNS resolution and TLS/response I/O are not covered by the TCP budget; this is not an end-to-end wall-clock guarantee. Do not retry HTTP requests (especially mutations), globally patch socket behavior, disable certificate checks, or permanently disable IPv6. Exhausted connections return an explicit MCP tool error. Credentials remain outside the repository. Existing task permissions and tool contracts are unchanged.
