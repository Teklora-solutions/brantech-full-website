# Private in-browser Knowledge Library previews

## Contract
GET `/library/<document>/preview/<version>/` reads only the current version, authorized through the existing visible-documents queryset and DOWNLOAD policy on every request. It never grants library/task access. Anonymous users must log in; nonstaff/deactivated users are denied; inaccessible/deleted/mismatched/stale versions are 404. Public AI publication approval does not expose originals.

Supported displays: PDF through the embedded browser PDF viewer on wider screens; narrow screens use a full-tab Read PDF link because native embedded plugins can clip content. PNG/JPEG inline; UTF-8 TXT/Markdown in an escaped, bounded text viewer (not interpreted HTML); DOCX converted to PDF by a self-hosted LibreOffice/Gotenberg service. Download original remains unchanged. Current-version URLs prevent quietly displaying replacement contents in an old page. Preview is local/internal rendering, independent of external processing/public approval, and never calls Google, Vertex or AI tools.

Native formats use explicit allowlisted MIME types, inline Content-Disposition, no-store/private, nosniff, same-origin framing and no referrer. Raw HTML/SVG/Office bytes are never served as HTML. Text previews read at most 256 KiB and visibly indicate truncation. PDF rendering depends on browser support, with open/download fallback links. Text is served in a minimal autoescaped HTML reader with a script-denying, sandboxed CSP; native PDF/image responses use strict MIME and deny-default CSP without sandbox, which would disable native PDF plugins. No promise to prevent saving/screenshotting authorized content or revoke bytes already delivered.

## DOCX conversion
Use a pinned, private-network-only Gotenberg sidecar with no exposed host port, credentials, shared application volumes, outbound document fetches or macros. Only the web container joins both the normal and internal converter network. Block all LibreOffice outbound URLs; disable Chromium/PDF processing routes. Bound queue, container CPU/memory, HTTP duration and PDF output size. The app calls only an explicitly configured internal/loopback converter address; no redirects, proxy inheritance or external viewer fallback.

Cache derived PDF files under private library storage by version and original SHA-256, with restrictive permissions and atomic writes. Use a filesystem singleflight lock to prevent duplicate concurrent conversions, reauthorize the current version after conversion, and audit successful previews without text/file names. Deletion immediately blocks access and scheduled purge removes derivatives and orphan cache/lock files. No new model/DB migration. Preview failures are explicit, do not change processing/clearance states, and retain original download plus existing extracted text.

## Tests and release
Cover formats/MIME/headers, no clearance dependency, auth/grant/group/deletion revocation, current-version pinning, missing files, escaping/truncation, disabled/down/invalid converter, output cap, caching/concurrency and purge. Verify real synthetic DOCX conversion plus browser views on isolated data, dark/light/mobile, without using production documents. DOCX fidelity depends on fonts/LibreOffice; preserve the original and do not claim perfect Word equivalence. Deployment must start the converter with the new Compose configuration; no live deployment is authorized.
